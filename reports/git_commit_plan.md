# Git commit plan

Use one commit per meaningful step. Good commit messages explain what changed and why.

Recommended trail:

1. `docs: add project overview and setup instructions`
2. `chore: add dependencies and repository structure`
3. `feat: implement data collection pipeline`
4. `feat: implement manual neural network training`
5. `feat: add canonical benchmark evaluator`
6. `experiment: v1 baseline behavioral cloning`
7. `experiment: v2 add more recovery data`
8. `experiment: v3 tune network width and epochs`
9. `experiment: v4 test multi-seed generalization`
10. `experiment: v5 add action smoothing and final benchmark`
11. `docs: add final iteration notes and comparison`
